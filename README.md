# Proyecto MLOps Unidad 2 

Descripción del Proyecto: Este proyecto corresponde al desarrollo de una solución de Machine Learning orientada a la predicción de enfermedades en pacientes a partir de diferentes variables clínicas y médicas.
-----------------------------------------------------------------------------------------------------------
# El objetivo principal es simular un entorno real de desarrollo MLOps, aplicando buenas prácticas de:

* Control de versiones
* Trabajo colaborativo
* Integración continua
* Despliegue continuo
* Dockerización
* Automatización mediante GitHub Actions
-----------------------------------------------------------------------------------------------------------
# Objetivo

* Construir una solución trazable, escalable y automatizada para la gestión del modelo predictivo, permitiendo:
-----------------------------------------------------------------------------------------------------------
# Evolución controlada del modelo
Gestión de cambios mediante ramas y Pull Requests
Ejecución automática de pruebas
Publicación automatizada de imágenes Docker
Simulación de un pipeline empresarial de CI/CD
